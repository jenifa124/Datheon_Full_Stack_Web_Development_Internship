# Datheon Full Stack Web Development Internship

**Personal Portfolio Website**  
Developed by **Most. Jenifa Akter** as part of the Datheon Full Stack Web Development Internship program.

---

## Project Overview

This is a responsive personal portfolio website built to showcase my skills, education, projects, and contact information as a Computer Science & Engineering student and aspiring software developer.

The website features a modern dark/light theme toggle, smooth navigation, interactive project details, and a clean, professional design suitable for both desktop and mobile devices.

---

---

## Features

- Responsive design (mobile, tablet & desktop)
- Dark / Light theme toggle with localStorage persistence
- Smooth scrolling navigation
- Mobile hamburger menu
- Interactive project details dialog
- Hero section with animated code card illustration
- About, Skills, Projects, Education & Contact sections
- Clean and accessible UI

---

## Technologies Used

- **HTML5**
- **CSS3** (Custom properties, Flexbox, Grid, responsive media queries)
- **JavaScript** (Vanilla JS – theme toggle, mobile menu, project modal)
